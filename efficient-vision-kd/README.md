# Efficient Vision KD Survey

> 방향, 제목, 목차 확정본은 [our paper.md](<our paper.md>), 실험 계획은 [experiments/PLAN.md](experiments/PLAN.md). 아래는 초기 정리.

**주제**: 비전 KD에서 *증류 학습 비용* 줄이는 방법 정리. (추론 비용 줄이는 KD 아님)

**주장 (초안)**: 효율 KD 논문은 줄인 비용만 보고함. 안 보여주는 것:
1. **옮겨 간 비용** — 예: 저장 공간, 사전 계산, 샘플 선택
2. **평균 정확도 밖 손실** — 예: 소수 그룹 정확도(WGA)

**빈자리**: 비전 KD 학습 비용 서베이 없음. 효율 KD를 그룹 강건성으로 평가한 논문 없음.
(언어 모델 쪽 비용 서베이 1편 → PART 2 #6)

## 중요하게 생각하는 지점

| 질문                              | 답할 것  | 현재 방향 (미확정)                |
| ------------------------------- | ----- | -------------------------- |
| **Q1. 어떤 efficient KD 방식이 있나?** | 나누는 축 | 비용의 어느 부분을 어떻게 줄이나로 나눔     |
| **Q2. 효율을 어떻게 나타내나?**           | 측정 방식 | 하나의 비용식으로 모든 방법을 같은 기준에 놓음 |
| **Q3. 효율화하면 무엇을 잃나?**           | 평가 방식 | 평균 정확도 말고 그룹별 성능도 봄(예시)    |

## Q1. 나누는 축

기준: 비용식(Q2)의 **어느 항을 어떻게 줄이나** (후보, 미확정)

| 축 | 하는 일 | 예시 |
|---|---|---|
| **Shrink** | 한 스텝 비용(단가)을 줄임 | MaskedKD |
| **Skip** | 샘플·teacher 호출·학습 구간을 건너뜀 | KD용 데이터 프루닝 |
| **Reuse** | 한 번 만들고 재사용 | FKD, TinyViT |
| **Substitute** | teacher·데이터를 싼 대역으로 | self-KD |

## Q2. 측정 방식

- 일회성 비용 + 반복 비용 + 저장을 **따로** 셈
- teacher 비용 포함한 실제 학습 비용으로 비교
- 안 적힌 값은 "보고 안 됨" (0 아님)

비용식 후보:
$$C = C_{prep} + N \cdot E \cdot (\rho \, c_T + c_S + c_{KD}) \quad + \text{저장 } S$$

## Q3. 평가 방식

- 평균 정확도 + 그룹별 정확도 (예시: WGA)
- 데이터셋, 지표 미정
