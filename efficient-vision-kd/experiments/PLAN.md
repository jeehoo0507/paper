# 실험 계획 (초안)

> 상태: 계획만 있음. 아직 돌린 실험 없음. 방법·데이터셋·지표는 바뀔 수 있음.

## 목표

1. **기여 2 (비용 계산)**: 효율 KD 방법이 비용을 어디서 줄이고 어디로 옮기는지 같은 코드·같은 GPU에서 측정.
2. **기여 3 (평가 방식)**: 평균 정확도로는 안 보이는 차이가 실제로 있는지 보여줌.

## 데이터셋

| 구분 | 데이터셋 | 역할 |
|---|---|---|
| 학습 (주) | ImageNet-100 (100 클래스, 약 13만 장, 224px) | 일반 성능, 클래스별, 분포 이동, 학습 곡선 |
| 학습 | Waterbirds (224px) | 그룹 강건성 |
| 평가만 | ImageNet-V2 (100 클래스만) | 분포 이동 |
| 평가만 | ImageNet-100 손상 버전 (검증셋에 손상 15종 × 강도 5) | 손상 강건성 |
| 평가만 | Flowers-102 또는 Oxford Pets (선형 평가) | 전이 성능 |

CIFAR-100은 뺌: 32px라 ViT 패치가 너무 적어서 토큰 기반 방법(MaskedKD)이 의미 없음.

| E1 | teacher가 학습 비용의 몇 %인가 | teacher–student 쌍 여러 개에서 시간만 측정 (학습 없음) |

## 비용 측정 (모든 실행 공통 로그)

teacher forward 시간, student 학습 시간 (따로), epoch당 시간, 최대 GPU 메모리, 일회성 시간 (logit 저장, teacher 체크포인트), 저장 용량, epoch별 검증 정확도, 그룹별·클래스별 정확도.

|---|---|---|---|---|

### 평균 정확도로 부족하다는 증거를 보이는 방법

- **방법 × 지표 표**: Full KD 대비 Δ. 평균 차이는 작은데 다른 지표가 크게 떨어지는 칸 강조.
- **순위 상관 (Kendall τ)**: 평균 정확도 순위 vs 지표별 순위.
- **MaskedKD 유지율 곡선**: 75 → 15%에서 평균과 WGA·손상 강건성이 다른 속도로 떨어지는지.

차이가 안 나오면 "이 설정에서는 평균이 충분했다"도 결과로 씀. 결론을 미리 정하지 않음.

| **합계** | **약 46** |

평가 전용 셋(V2, 손상, 전이)은 학습 모델마다 몇 분.

**관건**: ImageNet-100 실행 1개 시간. 1일 차에 B0를 몇 epoch 돌려 보고 전체 시간 계산.
**줄여야 하면**: ImageNet-100 epoch 단축 (모든 방법 동일) → 유지율 실험 Waterbirds만 → 전이 평가 생략.
