# 논문 읽기 메모 가이드

각자 맡은 파트의 파일(`1_Shrink.md` 등)에 논문마다 아래 양식을 채운다.
논문 목록과 PDF는 `../Related Work/Efficient KD papers/`의 같은 이름 폴더에 있다.

## 메모 항목

| 항목 | 적을 것 | 쓰이는 곳 |
|---|---|---|
| **효율화 방식** | 구체적으로 무엇을 어떻게 줄이는가 (teacher 연산 / 데이터 / 학습 길이 / teacher 자체 / KD 오버헤드) | 분류 축 |
| **얻는 것** | 절감 수치 + **무엇 대비인지** (student 단독 / 표준 KD / 다른 방법) | 비교표 |
| **잃는 것** | 정확도 변화, 생기는 제약 (증강 고정, teacher 고정 등) | 비교표, 쟁점 |
| **옮겨 간 비용** | 줄인 비용이 어디로 갔나 (저장 공간, 사전 계산, 샘플 선택, 데이터 합성) + 논문이 그걸 숫자로 보고했나 | 비용 계산, 쟁점 |
| **어떻게 쟀나** | 단위 (FLOPs / GPU-시간 / 실제 시간 / epoch / 샘플 수 / 배수), teacher forward를 셌나, 일회성 비용을 셌나, 하드웨어 | 비용 계산, 보고 방식 조사 |
| **설정** | teacher → student 쌍, 데이터셋, epoch | 비교표 |
| **평균 정확도 외 평가** | 클래스별 / OOD / 그룹별 등 평가를 했나, 했으면 무엇을 | 평가 방식 선정 |
| **위치** | 숫자마다 표·절·쪽 번호 | 원문 대조 |

## 규칙

- **절감 수치에는 항상 분모(무엇 대비)를 같이 적는다.** 예: MaskedKD의 −51%는 teacher 연산 대비이고, 전체 학습 대비가 아니다.
- **논문에 없는 값은 "보고 안 됨"으로 적는다.** 빈칸이나 추측으로 채우지 않는다.
- **그림에서만 읽은 수치는 "그림 N, 눈대중"으로 표시한다.**
- **축 분류가 애매하면 메모란에 적는다.** 나중에 모아서 정한다.

## 양식

```
### [논문명] (arXiv ID)
- 효율화 방식:
- 얻는 것: (수치, 무엇 대비)
- 잃는 것: (정확도 변화, 제약)
- 옮겨 간 비용: (어디로, 보고 여부)
- 어떻게 쟀나: 단위 = / teacher forward 셈? Y·N / 일회성 비용 셈? Y·N / 하드웨어 =
- 설정: teacher → student, 데이터셋, epoch
- 평균 정확도 외 평가: 없음 / 있음 (내용)
- 위치: 표 _, 절 _, 쪽 _
- 메모: (다른 논문과 충돌하는 주장, 축 분류가 애매한 점 등)
```
