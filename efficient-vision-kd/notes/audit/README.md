## 재확인한 내부 결과와 원문 접근 한계

- Waterbirds의 평균 −3.42%p와 WGA −28.83%p(Full KD→MaskedKD@29), WGA +23.57%p(MaskedKD@29→Rollout@29)는 공개 결과 표와 일치한다. 같은 표에서 WGA는 검증 세트의 진단 지표다. 원고가 채택한 2σ는 휴리스틱으로 표시하고, 별도 유의성 검정을 암시하는 표현을 피한다. [Waterbirds 원결과 표](https://github.com/jeehoo0507/Loop-Research-for-MaskedKD/blob/070ba8ae73d53c78fa66b32142c996f1f9652125/RESULTS_TABLE.md#L495-L519)
- 문헌 목록이 안내하는 `Related Work/survey paper/papers/` 디렉터리는 검토한 GitHub 커밋의 트리에 없다. 해당 두 서베이는 공개 링크에서 원문을 확인했다. 국문 초해상도 논문은 공개 서지·초록에서 연구 범위를 확인했지만 노트의 표 6 시간·PSNR은 원표 확인이 필요하다. 한 논문의 시간 비교만으로 분야 전체의 미보고 빈도를 주장할 수 없다. [GitHub 참고 서베이 폴더](https://github.com/jeehoo0507/paper/tree/9ef1f36c6ebd171fee35ed6e01f93d8d353f8ba6/efficient-vision-kd/Related%20Work/survey%20paper) · [초해상도 서지](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE12558170)
