### 01. Teacher's Pet ([arXiv: 2106.10494](https://arxiv.org/abs/2106.10494))
- 효율화 방식: 효율화 방법이 아님. 증류의 이득이 모든 클래스·하위집단에 고르게 돌아가는지를 분석. teacher의 오류가 student로 옮겨 가 증폭된다고 설명하고, teacher를 덜 믿어야 할 클래스에서 증류 비중을 낮추는 보정(AdaAlpha, AdaMargin)을 제안.
- 얻는 것 (관찰, 증류하지 않은 student 대비 변화):
  - ImageNet ResNet-34 자기 증류: 평균 +0.42%p, 하위 10개 클래스 평균 −2.60%p.
  - ImageNet ResNet-50 → ResNet-34: 평균 +0.39, 하위 10개 −2.05%p. ResNet-34 → ResNet-18: 평균 +0.15, 하위 10개 −3.60%p. (Table 2)
  - CIFAR-10/100 (균형)에서는 평균과 최악 클래스가 함께 오름 (CIFAR-100: +1.93, +3.33%p). 긴 꼬리 CIFAR-100에서는 평균 +2.17, 최악 클래스 −1.46%p. (Table 3)
- 잃는 것: 위 수치가 곧 "평균이 가리는 손실". 보정 방법은 ImageNet에서 하위 10개 클래스를 22.02 → 23.22%로 되돌리지만 증류 없는 23.64%에는 못 미침 (AdaAlpha, Table 5).
- 옮겨 간 비용: 해당 없음
- 어떻게 쟀나: 단위 = 해당 없음 (비용 측정 없음) / teacher forward 셈? 해당 없음 / 일회성 비용 셈? 해당 없음 / 하드웨어 = 확인 안 함
- 설정: ImageNet ResNet-50/34/18 조합 (자기 증류 포함), CIFAR-10/100 ResNet-56 자기 증류, 긴 꼬리판 CIFAR-10/100-LT·ImageNet-LT, iNaturalist. 표 형태 데이터(UCI Adult, 랜덤 포레스트)도 포함.
- 평균 정확도 외 평가: 있음. 클래스별 정확도를 정렬해 **하위 k개 클래스 평균** (k = 1, 10, 100)을 보고. Adult에서는 속성으로 나눈 하위집단 정확도.
- 위치: Fig. 1 (p. 2), Table 1 (p. 4), Fig. 2·Table 2·3 (p. 5), Table 4 (p. 7), Table 5·6 (p. 10)
- 메모:
  - 효율화 이전의 Full KD부터 하위 클래스가 손해를 볼 수 있다는 직접 근거. 우리 실험에서 Full KD 대 CE의 하위 클래스 지표를 먼저 기록해야 하는 이유.
  - 균형 데이터·클래스 수가 적은 경우에는 손해가 안 보였다는 점도 같이 적어야 함. 현상이 데이터에 따라 다름.
  - ImageNet은 클래스당 검증 이미지가 50장이라 하위 10개 클래스 지표의 잡음이 큼. seed 수와 구간은 확인 안 함.

### 02. DeDiER (Using Early Readouts to Mediate Featural Bias) ([arXiv: 2310.18590](https://arxiv.org/abs/2310.18590))
- 효율화 방식: 효율화 방법이 아님. 증류에서 student가 가짜 상관에 더 취약해지는 문제를 다룸. student의 앞쪽 층에 보조 분류기(조기 판독)를 달아 "확신하면서 틀리는" 샘플을 찾고, 그 샘플의 증류 손실 가중치를 높임. 그룹 라벨이 필요 없음.
- 얻는 것 (Waterbirds, ResNet-50 teacher → ResNet-18 student, 최저 그룹 정확도): 지도학습 student 33.8%, KD(λ=0.5) 67.9%, KD(λ=1) 84.9%, DeTT 87.5%, 제안 89.8%. teacher는 91.4%. (Table 1)
- 잃는 것: [실측·원논문] 일반 KD는 평균 정확도가 비슷해도 최저 그룹에서 teacher보다 크게 낮음 (Waterbirds KD(λ=0.5): 평균 87.9%, 최저 그룹 67.9% vs teacher 92.6%, 91.4%). 그룹별로 보면 SimKD는 (물새, 육지 배경) 그룹에서 71.4%로 teacher 91.7%와 20%p 차이. (Table 1·2)
- 옮겨 간 비용: 보조 분류기의 학습과 forward. 숫자 보고 안 됨.
- 어떻게 쟀나: 단위 = 해당 없음 / teacher forward 셈? 해당 없음 / 일회성 비용 셈? 해당 없음 / 하드웨어 = 확인 안 함
- 설정: Waterbirds, CelebA (ResNet-50 → ResNet-18), CivilComments-WILDS, MultiNLI (BERT → DistilBERT). teacher는 최저 그룹 정확도가 높은 모델 (Waterbirds 91.4%).
- 평균 정확도 외 평가: 있음. **최저 그룹 정확도**와 그룹별 정확도 (Waterbirds 4그룹, CelebA 4그룹). 표에 "그룹 주석 사용 여부" 열을 둠.
- 위치: Fig. 1 (p. 2), Table 1 (p. 7), Table 2·Fig. 5 (p. 8), Table 3–5 (p. 11–12)
- 메모:
  - 여기서 teacher는 이미 편향이 줄어든 모델임 (최저 그룹 91.4%). 우리 실험의 teacher는 일반 미세조정 모델이라 조건이 다름. "Waterbirds에서 KD가 최저 그룹을 크게 올린다"는 이 논문의 수치를 그대로 기대하면 안 됨.
  - KD 손실 비중이 클수록(λ=1) 최저 그룹이 좋아진다는 결과는 teacher가 편향이 적을 때의 이야기.

### 03. Debiased Distillation by Transplanting the Last Layer (DeTT) ([arXiv: 2302.11187](https://arxiv.org/abs/2302.11187))
- 효율화 방식: 효율화 방법이 아님. teacher가 편향이 없어도 편향된 데이터로 증류하면 student가 편향된다는 것을 보이고, teacher의 마지막 층을 student에 그대로 이식한 뒤 나머지는 특징 증류(편향 충돌 샘플 가중)로 학습하는 방법을 제안.
- 얻는 것 (Waterbirds, 최저 그룹 정확도): teacher 90.8%, KD(α=0.5) 67.9%, KD(α=1) 84.9%, SimKD 71.4%, 제안 87.5%. CelebA는 teacher 90.7%, KD(α=0.5) 62.0%, 제안 89.5%. (Table 1)
- 잃는 것: [실측·원논문] 일반 KD로는 teacher의 강건성이 전부 전달되지 않음 (위 수치). 가중 배수를 낮추면 제안 방법도 떨어짐 (Waterbirds 배수 5에서 76.6%, 50에서 87.5%). (Table 3)
- 옮겨 간 비용: 투영층 추가 (student 크기 증가), 편향 충돌 샘플을 찾기 위한 선행 학습. 숫자 보고 안 됨.
- 어떻게 쟀나: 단위 = 해당 없음 / teacher forward 셈? 해당 없음 / 일회성 비용 셈? 해당 없음 / 하드웨어 = 확인 안 함
- 설정: Waterbirds, CelebA, CivilComments, MultiNLI. teacher는 편향을 줄인 모델. 일부 검증 샘플의 그룹 주석만 사용.
- 평균 정확도 외 평가: 있음. **최저 그룹 정확도**, 그룹별 정확도 (Table 4·5). 표에 그룹 주석 사용 범위(전체 / 소수 검증 샘플 / 없음)를 표시.
- 위치: Fig. 1 (p. 2), Table 1 (p. 6), Table 2–5 (p. 7), Table 6 (p. 8)
- 메모: 02번과 같은 벤치마크·같은 기준선 수치를 공유함 (KD, SimKD 수치가 동일). 3_Reuse 12번 SimKD(분류기 재사용)가 그룹 지표에서는 약하다는 점이 여기서 드러남.

### 04. What is Left After Distillation? ([arXiv: 2410.08407](https://arxiv.org/abs/2410.08407))
- 효율화 방식: 효율화 방법이 아님. 균형 데이터에서도 증류가 클래스별 정확도를 얼마나 바꾸는지, 온도가 공정성 지표에 어떤 영향을 주는지를 통계 검정으로 측정.
- 얻는 것 (관찰):
  - ImageNet ResNet-50 → ResNet-18: 증류하지 않은 student와 비교해 정확도가 유의하게 달라진 클래스 수가 온도 2에서 77개, 온도 10에서 408개 (약 41%). 평균 정확도는 68.64 → 68.93~70.83%로 오름.
  - CIFAR-100 ResNet-56 → ResNet-20: 온도 2에서 5개, 온도 10에서 22개. (Table 1)
  - 공정성: CelebA에서 온도를 올리면 EOD와 DPD가 내려감 (증류 없음 EOD 6.11 → 온도 4에서 5.36). (Table 2)
- 잃는 것: 평균이 오르는 동안 많은 클래스가 유의하게 바뀜. 논문은 이것을 반드시 나쁜 결과로 단정하지 않고, 사용 맥락에 따라 판단해야 한다고 적음.
- 옮겨 간 비용: 해당 없음
- 어떻게 쟀나: 단위 = 해당 없음 / teacher forward 셈? 해당 없음 / 일회성 비용 셈? 해당 없음 / 하드웨어 = 확인 안 함
- 설정: SVHN, CIFAR-10/100, Tiny ImageNet, ImageNet. ResNet-56 → ResNet-20, DenseNet-169 → DenseNet-121, ResNet-50 → ResNet-18, ViT-Base → TinyViT. 온도 2~10, 5회 반복. 공정성은 CelebA, Trifeature, HateXplain.
- 평균 정확도 외 평가: 있음. (1) **클래스별 정확도 변화의 유의성 검정**으로 영향받은 클래스 수를 셈, (2) 집단 공정성 지표 EOD·DPD, (3) 개별 공정성.
- 위치: Fig. 1·Table 1 (p. 6), Fig. 3 (p. 8), Table 2 (p. 10), Table 3·4 (p. 11–12)
- 메모: 온도가 클래스별 효과를 크게 좌우함. 우리 실험에서 온도를 고정하고 예산만 바꾸는 이유와, 온도가 다르면 결과가 달라질 수 있다는 한계의 근거. EOD·DPD는 최저 그룹 정확도와 다른 지표라 같은 표에 섞지 않음.

### 05. When Masking Helps or Hurts Robustness in Compressed CLIP ([arXiv: 2609.39704](https://arxiv.org/abs/2609.39704))
- 효율화 방식: 효율화 방법이 아님 (추론 시 토큰 프루닝의 평가). CLIP에서 의미 기반 마스킹으로 토큰을 줄였을 때 최저 그룹 정확도가 오르는지 내리는지가 데이터셋마다 크게 다르다는 것을 보이고, 라벨 없이 그 방향을 미리 예측하는 지표(SIM)를 제안.
- 얻는 것 (관찰, 토큰 50% 예산, 8개 데이터셋 평균, 압축 전 대비 최저 그룹 정확도의 상대 변화): FastV +2.3%, EViT −4.3%, PatchRank −5.2%, 텍스트 기반 프루닝 −36.7%, 의미 마스킹 −31.6%. (Table 1)
- 잃는 것: [실측·원논문] 같은 방법이 데이터셋에 따라 반대로 작용함. 의미 마스킹은 Waterbirds에서 50.8 → 67.3%로 오르지만 CelebA 79.6 → 64.7%, ImageNet-9 87.5 → 26.3%, OxfordPets 52.6 → 0.0%로 떨어짐. (Table 2) 원인으로 "배경 패치가 실제 물체보다 텍스트 유사도가 높게 나오는" 뒤바뀜을 지목.
- 옮겨 간 비용: 마스킹용 분할 단계가 추론 시간의 병목 (기준의 3.5배, 개선 후 1.75배). (초록, 부록 G)
- 어떻게 쟀나: 단위 = 이미지당 추론 지연(ms) / teacher forward 셈? 해당 없음 (증류 아님) / 일회성 비용 셈? 해당 없음 / 하드웨어 = NVIDIA A100 1장
- 설정: OpenCLIP ViT-L/14 등 CLIP 6종, 가짜 상관 벤치마크 8종 (Waterbirds, UrbanCars, CelebA, MetaShifts, ImageNet-9, OxfordPets, Caltech101, ImageNet-D). 제로샷 추론, 학습 없음.
- 평균 정확도 외 평가: 있음. **최저 그룹 정확도**의 압축 전 대비 상대 변화, "나빠진 / 좋아진 데이터셋 수".
- 위치: Table 1 (p. 6), Fig. 3·Table 2 (p. 7), Table 3 (p. 12), Table 7·8 (p. 17)
- 메모:
  - 개입 시점이 다름. 이 논문은 **추론 때** 모델 입력의 토큰을 줄이고, MaskedKD는 **학습 때** teacher 입력의 토큰만 줄임. 다만 "어떤 토큰을 남기는지가 그룹별 결과를 뒤집는다"는 결론은 우리 Waterbirds 결과(같은 15%에서 선택 규칙에 따라 최저 그룹 38.6% 대 62.2%)와 같은 방향.
  - Waterbirds 하나만 보면 결론이 뒤집힐 수 있다는 경고. 그룹 데이터셋을 둘 이상 써야 하는 이유.

### 06. Later Is Better: Token Reduction under Distribution Shift ([arXiv: 2610.07758](https://arxiv.org/abs/2610.07758))
- 효율화 방식: 효율화 방법이 아님 (추론 시 토큰 축소의 평가와 개선). 같은 연산량에서 토큰을 **어느 층에서** 줄이는지에 따라 분포 이동 아래의 정확도가 달라짐을 보이고, 뒤쪽 층에 축소를 몰아 주는 일정을 제안.
- 얻는 것 (DeiT-S, ImageNet-C 강도 5, 15종 평균, 연산 −26%): 균등 일정 37.99% → 뒤쪽 집중 일정 39.16% (+1.17%p). 압축 전은 39.40%. 연산 −7%에서는 +0.26%p. (Table 1)
- 잃는 것: [실측·원논문] 토큰 축소율을 높일수록 압축 전 모델과의 격차가 분포 이동 아래에서 벌어짐 (균등 일정: −7%에서 39.14% → −37%에서 36.67%). (Table 1)
- 옮겨 간 비용: 해당 없음 (추가 추론 비용 없음이라고 명시)
- 어떻게 쟀나: 단위 = 추론 GFLOPs (같은 GFLOPs에서 비교) / teacher forward 셈? 해당 없음 / 일회성 비용 셈? 해당 없음 / 하드웨어 = 확인 안 함
- 설정: 학습 없는 토큰 축소 5종 (ToMe, EViT, ATS, ATC, PiToMe), 백본 9종 (DeiT, ViT, CLIP, MAE). 추론만.
- 평균 정확도 외 평가: 있음. **손상 강건성** (ImageNet-C 15종 × 강도, ImageNet-3DCC), **자연 분포 이동** (ImageNet-A, R, V2, Sketch, DomainNet-126), 세부 분류 손상 (NaBirds-C). (Table 4·5)
- 위치: Table 1 (p. 7), Table 2·3 (p. 8), Table 4·5 (p. 9)
- 메모: "얼마나 줄였는가"와 "어떻게 줄였는가"를 분리해야 한다는 설계 근거. 같은 연산량에서도 줄이는 방식이 강건성을 바꿈. 우리 Shrink 축에서 선택 규칙을 따로 대조하는 이유와 같음. 손상 평가를 15종 평균으로 보고하는 형식도 참고.

### 07. DRoP: Distributionally Robust Data Pruning ([arXiv: 2404.05579](https://arxiv.org/abs/2404.05579))
- 효율화 방식: 효율화 방법은 데이터 프루닝 (KD 아님). 기존 프루닝 방법이 클래스별로 편향된 분류기를 만든다는 것을 보이고, 클래스별 프루닝 비율을 조절한 뒤 클래스 안에서는 무작위로 고르는 방법을 제안.
- 얻는 것 (CIFAR-100, 30%만 남김, 최악 클래스 정확도): 무작위 24.7% → 무작위 + DRoP 34.3%. 전체 데이터는 35.8%. 절반을 남기면 무작위 + DRoP가 45.3%로 전체 데이터보다 높음. (Table 2)
- 잃는 것:
  - [실측·원논문] 평균 정확도는 조금 내려감 (CIFAR-100 30%: 59.1 → 57.2%).
  - [실측·원논문] 점수 기반 프루닝은 최악 클래스에서 크게 무너짐: CIFAR-100 30%에서 GraNd 평균 40.4%, 최악 12.3%. TinyImageNet 30%에서 GraNd·Forgetting의 최악 클래스 1.0%. (Table 2)
- 옮겨 간 비용: 클래스별 비율을 정하기 위한 선행 학습 (클래스별 검증 오류 추정). 숫자는 확인 안 함.
- 어떻게 쟀나: 단위 = 남긴 데이터 비율 / teacher forward 셈? 해당 없음 / 일회성 비용 셈? N / 하드웨어 = 확인 안 함
- 설정: CIFAR-10/100, TinyImageNet, ImageNet. ResNet 계열, 3 seed. 남긴 비율 0.3 / 0.5 / 0.8.
- 평균 정확도 외 평가: 있음. **최악 클래스 정확도**를 평균과 나란히 보고.
- 위치: Table 1 (p. 16), Table 2 (p. 22)
- 메모: Skip(데이터)에서 "예산을 줄이면 최악 클래스가 먼저 무너진다"의 KD 없는 선행 근거. 여기서 단위는 **클래스**이고 클래스 안의 속성 그룹이 아님. 무작위 선택이 점수 기반보다 최악 클래스에서 안전하다는 점은 2_Skip 02번과 일관됨.

### 08. Impact of Coreset Selection on Spurious Correlations ([arXiv: 2507.11690](https://arxiv.org/abs/2507.11690))
- 효율화 방식: 효율화 방법은 코어셋 선택 (KD 아님). 데이터 선택이 데이터의 가짜 상관 수준과 그 데이터로 학습한 모델의 강건성에 어떤 영향을 주는지를 넓게 분석. 벤치마크 10종, 점수 5종, 선택 정책 5종.
- 얻는 것 (관찰, 40% 선택, 최저 그룹 정확도, Waterbirds): 무작위 58.2%, 그룹 균형 무작위 83.3%, EL2N 기준 어려운 샘플 74.6%, 쉬운 샘플 30.2%. (Table 1)
- 잃는 것:
  - [실측·원논문] 어려운 샘플 위주 선택이 편향이 가장 낮은 부분집합을 만들지만, 선택 비율이 아주 작아지면 최저 그룹 정확도가 오히려 낮아짐. (4.2–4.3절)
  - [실측·원논문] 데이터셋마다 유리한 정책이 다름. CelebA(머리색)에서는 쉬운 샘플 79.0%가 어려운 샘플 38.3%보다 높음. (Table 1)
- 옮겨 간 비용: 점수 계산 (학습 동역학 기반 점수는 선행 학습 필요). 숫자 보고 안 됨.
- 어떻게 쟀나: 단위 = 선택 비율 / teacher forward 셈? 해당 없음 / 일회성 비용 셈? N / 하드웨어 = 확인 안 함
- 설정: cMNIST, Waterbirds, UrbanCars 3종, Metashift, CivilComments, NICO, MultiNLI, CelebA. 점수는 EL2N 등 학습 기반과 자기지도 임베딩 기반.
- 평균 정확도 외 평가: 있음. **최저 그룹 정확도**, 선택된 부분집합의 편향 수준. 평균 정확도가 무작위보다 10%p 이상 무너진 경우를 따로 표시.
- 위치: Table 1 (p. 8), Table 2 (p. 16), Table 3–5 (p. 19–20)
- 메모: Skip(데이터)에서 선택 규칙이 그룹 지표를 바꾼다는 근거. 무작위 기준선에 "그룹 균형 무작위"를 따로 두었는데, 이는 그룹 라벨을 쓰는 상한에 해당함. 우리 실험은 그룹 라벨을 학습에 쓰지 않으므로 무작위(58.2%) 쪽이 비교 대상.

### 09. Group DRO (Waterbirds) ([arXiv: 1911.08731](https://arxiv.org/abs/1911.08731))
- 효율화 방식: 효율화 방법이 아님. 그룹별 최악 손실을 줄이는 학습(그룹 DRO)과, 과매개변수 모델에서는 강한 정규화가 함께 있어야 최저 그룹 일반화가 좋아진다는 것을 보임. Waterbirds 벤치마크의 출처.
- 얻는 것 (Waterbirds, 평균 / 최저 그룹 정확도):
  - 표준 정규화: ERM 97.3 / 60.0%, 그룹 DRO 97.4 / 76.9%.
  - 강한 L2 정규화: ERM 95.7 / 21.3%, 그룹 DRO 96.6 / 84.6%.
  - 조기 종료: ERM 93.8 / 6.7%, 그룹 DRO 93.2 / 86.0%. (Table 1)
- 잃는 것: [구조] 학습 데이터의 그룹 라벨이 필요함. 정규화 없이는 그룹 DRO도 최저 그룹에서 일반화가 나쁨.
- 옮겨 간 비용: 해당 없음
- 어떻게 쟀나: 단위 = 해당 없음 / teacher forward 셈? 해당 없음 / 일회성 비용 셈? 해당 없음 / 하드웨어 = 확인 안 함
- 설정: Waterbirds, CelebA (ResNet-50, ImageNet 사전학습), MultiNLI (BERT).
- 평균 정확도 외 평가: 있음. **최저 그룹 정확도**의 표준 정의 (라벨 × 가짜 속성으로 나눈 그룹 중 최저).
- 위치: Table 1·Fig. 2 (p. 5)
- 메모: 같은 ERM이라도 정규화와 종료 시점에 따라 Waterbirds 최저 그룹이 60.0%에서 6.7%까지 달라짐. 우리 실험에서 "마지막 epoch, 조기 종료 없음"을 고정하고 그 사실을 적어야 하는 이유. 평균 정확도는 그룹 비율로 가중한 값이라는 점도 표기 필요.

### 10. Last Layer Re-Training is Sufficient (DFR) ([arXiv: 2204.02937](https://arxiv.org/abs/2204.02937))
- 효율화 방식: 효율화 방법이 아님 (다만 계산은 매우 가벼움). 가짜 상관에 의존하는 모델도 핵심 특징은 이미 학습했다는 것을 보이고, 그룹 균형이 맞는 소량의 데이터로 **마지막 층만** 다시 학습해 최저 그룹 정확도를 회복.
- 얻는 것 (최저 그룹 / 평균 정확도): Waterbirds ERM 74.9 / 98.1% → DFR 92.9 / 94.2% (그룹 DRO 91.4 / 93.5%). CelebA 46.9 / 95.3% → 88.3 / 91.3%. (Table 2)
- 잃는 것: [구조] 재학습에 그룹 라벨이 있는 검증 데이터를 씀. 평균 정확도는 조금 내려감 (Waterbirds 98.1 → 94.2%).
- 옮겨 간 비용: 해당 없음. 마지막 층 재학습은 GPU 1장에서 수 분이라고 적음 (초록).
- 어떻게 쟀나: 단위 = 해당 없음 / teacher forward 셈? 해당 없음 / 일회성 비용 셈? 해당 없음 / 하드웨어 = 확인 안 함
- 설정: Waterbirds, CelebA (ResNet-50, ImageNet 사전학습), MultiNLI, CivilComments (BERT). 5회 평균.
- 평균 정확도 외 평가: 있음. **최저 그룹 정확도**. 표에 방법별로 학습·검증 데이터의 그룹 라벨 사용 여부를 표시. 배경·질감 의존도 평가 (ImageNet 계열).
- 위치: Table 2 (p. 7)
- 메모: "표현은 괜찮고 마지막 층이 문제"라는 관점은 우리 결과 해석에 쓸 수 있음. 효율 KD로 최저 그룹이 무너진 student에 DFR을 적용해 회복되는지를 보면, 손실이 표현에 있는지 분류기에 있는지 가를 수 있음 (추가 분석 후보). 평균 정확도는 학습 데이터의 그룹 비율로 가중한 값.

### 11. Group Robustness is in the Details ([arXiv: 2407.13957](https://arxiv.org/abs/2407.13957))
- 효율화 방식: 효율화 방법이 아님. 사전학습 모델을 미세조정할 때 클래스 균형화 방법(업샘플링, 손실 가중, 부분집합, 혼합)과 모델 선택 방식, 모델 크기가 최저 그룹 정확도를 어떻게 바꾸는지 분석.
- 얻는 것 (관찰):
  - 흔히 쓰는 업샘플링과 손실 가중은 epoch이 지날수록 최저 그룹 정확도가 떨어져, 균형화를 안 한 것과 다르지 않게 될 수 있음. (초록)
  - 그룹 라벨 없이도 모델 선택이 가능함. **최악 클래스 정확도**로 고른 설정이 최저 그룹 정확도로 고른 설정과 대부분 일치 (Waterbirds 81.1%, CelebA 74.1%, CivilComments 77.6%). (Table 1)
  - 모델을 키우면 대체로 최저 그룹에 유리하지만 적절한 클래스 균형화가 있을 때만. (4절)
- 잃는 것: 해당 없음 (방법 간 세부 차이가 결과를 뒤집는다는 것 자체가 결론).
- 옮겨 간 비용: 해당 없음
- 어떻게 쟀나: 단위 = 해당 없음 / teacher forward 셈? 해당 없음 / 일회성 비용 셈? 해당 없음 / 하드웨어 = 확인 안 함
- 설정: Waterbirds, CelebA, CivilComments, MultiNLI. 사전학습 모델 미세조정, 3 seed. 모델 구조는 확인 안 함.
- 평균 정확도 외 평가: 있음. **최저 그룹 정확도**, 그리고 그룹 라벨 없는 대용 지표(최악 클래스 정확도, 편향 비지도 검증 점수)의 타당성 검증.
- 위치: Table 1 (p. 7)
- 메모: 체크포인트·설정 선택에 그룹 라벨을 썼는지를 실험마다 밝혀야 한다는 근거. 우리 실험은 선택에 그룹 라벨을 쓰지 않으므로 이 논문의 "그룹 주석 없음" 행과 같은 조건이라고 적으면 됨. 학습 epoch에 따라 최저 그룹이 내려갈 수 있다는 관찰은 "마지막 epoch만 보고" 설계의 위험 요소.
