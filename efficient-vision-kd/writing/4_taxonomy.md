# 4절 Taxonomy 지시서

**담당**: 축마다 한 명. **결과물**: 축별로 방법 표 1개, 축 문단 1개, 경계 논문 목록.

이 절이 답하는 질문: 이 방법은 비용식의 어느 항을 바꾸는가.

| 축 | 바꾸는 것 | 새로 드는 것 |
|---|---|---|
| Shrink | teacher 호출 1회의 비용 (토큰, 해상도, 깊이) | 무엇을 남길지 고르는 연산 |
| Skip | teacher 호출 횟수 (데이터 / 샘플 / 학습 구간) | 무엇을 건너뛸지 고르는 연산 |
| Reuse | 같은 출력을 다시 계산하는 횟수 | 저장 공간, 생성 시간 |
| Substitute | teacher나 데이터 자체 | 대체물을 준비하는 비용 |

## 정리할 것

### (1) 방법 표

자기 축의 논문을 한 편당 한 줄로 넣는다. 열 이름의 기호는 3절 기호표가 나오면 맞춘다.

| 방법 | 하위 갈래 | 줄이는 비용 | 새로 드는 비용 | 보고한 절감률 | 절감률의 분모 | 설정 (데이터, 모델 쌍) | 위치 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

- **절감률의 분모**: teacher 연산 대비 / 전체 학습 대비 / student 단독 학습 대비. 논문이 밝히지 않았으면 "불명".
- **새로 드는 비용**: 논문이 숫자로 보고했는지도 같이 적는다 (보고 / 언급만 / 미보고).

### (2) 하위 갈래

자기 축을 2–4개 갈래로 나누고, 갈래마다 한 줄로 정의한다. 예: Skip은 데이터 / 샘플 / 학습 구간.

### (3) 축 문단 (5–7문장)

논문을 하나씩 설명하지 않는다. 아래 세 가지만 쓴다.

1. 이 축은 teacher 신호에서 **무엇을 빼는가**.
2. 그 대가로 **어떤 비용이 새로 생기는가**.
3. 이 축의 논문들이 **공통으로 보고하지 않는 것**은 무엇인가. (5절 체크표에서 센 숫자로)

### (4) 경계 논문

- 두 축에 걸치는 논문: 어느 축에 넣었고 왜인지 한 줄.
- teacher 연산을 실제로는 줄이지 않는 논문: 따로 표시한다. (예: KD 손실만 바꾸는 논문)
- 뺀 논문: 이유 한 줄. 2절 담당에게 전달한다.

## 축별 메모

- **Shrink**: 손실 쪽 논문(DKD, ITRD, Projector, PESF-KD, DIST)은 teacher 연산을 줄이지 않는다. 축 안에 둘지 따로 뺄지 의견을 적는다.
- **Skip**: 데이터를 고르는 방법은 선택 점수를 얻는 비용(추가 학습 여부)을 꼭 적는다.
- **Reuse**: 생성 시간과 저장 용량을 **둘 다** 보고했는지, 하나만 했는지 구분한다.
- **Substitute**: 대체 teacher나 합성 데이터를 만드는 비용을 논문이 셌는지 적는다. teacher 역할을 줄이는 것 / teacher를 약하게 만드는 것 / 데이터를 바꾸는 것으로 갈래를 나눈다.
