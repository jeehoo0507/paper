# 3절 Cost Accounting: 구조와 기호표

**담당**: 지후. **분량**: 본문 1쪽 안팎. 4, 5절의 표는 이 절의 기호와 범위 이름을 그대로 쓴다.

이 절이 답하는 질문: 서로 다른 방법의 비용을 같은 기준으로 어떻게 읽는가.
논문별 사례는 여기서 다루지 않는다. 방법 설명은 4절, 논문이 보고한 수치는 5절로 보낸다.

## 구조

| 소절 | 내용 | 표·그림 |
|---|---|---|
| 3.1 비용 분해 | Full KD 학습에서 일어나는 연산의 종류: teacher 순전파, student 순전파·역전파, 선택 연산, 데이터·캐시 읽기, 준비(teacher 학습, 캐시 생성, 선택 점수) | 그림 3-1 한 스텝 도식 |
| 3.2 비용식 | 연산 종류마다 횟수 × 단가. 단가는 측정값이고 단위(연산량, 시간)를 바꿔 같은 식을 쓴다. 저장 용량은 따로 적는다. 선행 식 인용 한두 줄 | 표 3-1 기호표 |
| 3.3 세는 범위 | 범위 4가지의 정의. 범위 사이를 잇는 공식. 예시 숫자 한 줄 | 표 3-2 범위 |
| 3.4 축과의 연결 | 식의 어느 자유도를 바꾸는가로 4축을 정의. 4절로 넘어감 | 표 3-3 축 × 항 |
| 3.5 이 식이 다루지 않는 것 | 성능, 탐색 비용, 설정마다 다른 teacher 비중 | – |

## 비용식

$$C \;=\; \sum_{j}\frac{n_j\,u_j}{N_j} \;+\; n_T u_T + n_S u_S + n_{\mathrm{sel}} u_{\mathrm{sel}} + n_{\mathrm{io}} u_{\mathrm{io}}$$

저장 용량 $M$은 이 식에 더하지 않고 따로 보고한다.

### 표 3-1 기호표

| 기호 | 뜻 |
|---|---|
| $n_T$, $u_T$ | teacher 순전파 횟수, 1회 단가 |
| $n_S$, $u_S$ | student 순전파·역전파 횟수, 1회 단가 |
| $n_{\mathrm{sel}}$, $u_{\mathrm{sel}}$ | 무엇을 남기거나 건너뛸지 고르는 연산의 횟수, 단가 |
| $n_{\mathrm{io}}$, $u_{\mathrm{io}}$ | 데이터와 캐시를 읽는 횟수, 단가 |
| $j$ | 한 번만 드는 준비 항목: teacher 학습, 캐시 생성, 선택 점수 계산 |
| $N_j$ | 준비 항목 $j$를 함께 쓰는 student 학습 횟수 |
| $M$ | 저장한 teacher 출력의 크기 |
| $s_T$ | 반복 비용에서 teacher가 차지하는 비중, $n_T u_T / (n_T u_T + n_S u_S + \dots)$. 단위마다 다르다 |

- 단가 $u$는 측정값이다. 연산량으로 재면 연산량 식, 초로 재면 시간 식이 된다.
- 토큰 비율, 데이터 비율 같은 설정값은 식에 넣지 않는다. 그 설정에서 측정된 $n$과 $u$를 넣는다.

### 표 3-2 세는 범위

| 범위 | 세는 것 | 4, 5절 표의 열 이름 |
|---|---|---|
| S1 | $n_T u_T$ (연산량) | teacher 연산 |
| S2 | 반복 항 전체 (연산량) | 전체 학습 연산 |
| S3 | 반복 항 전체 (시간) | 실제 시간 |
| S4 | S3 + 준비 항 | 준비 비용 포함 |

범위를 잇는 공식 (teacher 쪽만 줄이는 방법):

$$\text{전체 절감률} \;=\; s_T \times \text{teacher 절감률} \;-\; \text{새로 생긴 비용의 비중}$$

예시 (우리 측정, DeiT-B → DeiT-Ti, MaskedKD 토큰 50%): 연산량 기준 $s_T = 0.82$이므로 $0.82 \times 0.50 = 0.41$, 실측 −41%와 맞는다. 시간 기준 숫자는 실제 데이터로 다시 잰 뒤 넣는다.

student 쪽도 같이 줄이는 방법(데이터를 줄이는 Skip 등)에는 이 공식을 쓰지 않는다.

### 표 3-3 축 × 항

| 축 | 바꾸는 것 | 새로 생기는 것 |
|---|---|---|
| Shrink | $u_T$ (teacher 1회 단가) | $n_{\mathrm{sel}} u_{\mathrm{sel}}$ |
| Skip | $n_T$ (teacher 횟수). 데이터를 줄이면 $n_S$도 같이 줄어든다 | $n_{\mathrm{sel}} u_{\mathrm{sel}}$ |
| Reuse | $n_T$를 반복 항에서 준비 항으로 옮긴다 | 캐시 생성, $n_{\mathrm{io}} u_{\mathrm{io}}$, $M$ |
| Substitute | teacher 연산 자체를 다른 것으로 바꾼다 ($u_T$ 또는 teacher 준비 항) | 대체물의 준비 비용 |

## 정한 것

- 공개된 사전학습 가중치의 학습 비용은 준비 항에 넣지 않고 "외부 제공"으로 표시한다. 대상 데이터에 미세조정한 비용은 넣는다.
- 실제 시간(S3)에는 데이터 읽기와 캐시 읽기를 포함한다.
- 하이퍼파라미터 탐색과 평가 시간은 넣지 않는다.

## 쓰지 않는 문장

- "teacher 비중이 절감의 상한이다"를 조건 없이 쓰지 않는다. teacher 쪽만 줄이는 방법에 한정한다.
- "비용 회계를 처음 제안한다"고 쓰지 않는다. 언어 모델 증류의 에너지 회계와 Distillation Scaling Laws에 같은 꼴의 식이 있다.
