# 5절 What the Literature Reports 지시서

**담당**: 체크표는 축마다 한 명, 집계는 Skip 담당이 취합.

이 절이 답하는 질문: 발표된 논문에서 실제로 확인되는 비용과 지표는 무엇인가.

## (1) 보고 체크표

논문 한 편당 한 줄. 원문을 열어서 칸마다 아래 네 값 중 하나를 적는다.

| 값 | 뜻 |
|---|---|
| 수치 | 숫자로 보고함. 값과 위치(표, 쪽)를 같이 적는다 |
| 언급 | 말로는 다루지만 숫자가 없음 |
| 미보고 | 해당되는데 적지 않음 |
| 해당 없음 | 이 방법에는 그 비용이 없음 |

### 아낀 것 (비용)

열 이름은 [CHECKLIST.md](CHECKLIST.md) A항과 같다. 실험 결과표도 같은 열을 쓴다.

| 논문 | teacher 연산 | 전체 학습 연산 | 실제 시간 | 준비 비용 (teacher 학습, 캐시 생성, 선택 점수) | 저장 용량 | 측정 단위 | 하드웨어 명시 | 본 판본 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

- **teacher 연산**: teacher 순전파를 비용에 넣었는가.
- **전체 학습 연산**: teacher + student + 선택 연산을 합친 값을 냈는가.
- **준비 비용**: 한 번만 드는 비용을 숫자로 냈는가. 무엇을 냈는지(생성 시간만, 저장만, 둘 다)를 구분해 적는다.
- **측정 단위**: FLOPs / GPU 시간 / 실제 시간 / epoch / 샘플 수 / 배수 중 쓴 것을 전부.
- **절감률의 분모**: 수치 칸에 "무엇 대비"를 같이 적는다.

### 치른 것 (성능)

| 논문 | 평균 정확도 | 그룹별, 최저 그룹 | 클래스별, 꼬리·하위 클래스 | 보정 (ECE, NLL) | teacher 일치율 | 분포 이동, 손상 | 전이, 다른 과제 | seed 수 | 표준편차 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

### 환산 (가능한 논문만)

보고된 절감률을 다른 범위로 다시 읽는다. 넣은 값과 식을 반드시 적고, "우리 환산"이라고 표시한다.

| 논문 | 논문이 보고한 절감 (범위) | 환산에 쓴 값 (teacher·student 연산량, 호출 비율) | 전체 학습 연산 기준 환산값 | 환산 불가 사유 |
|---|---|---|---|---|
| | | | | |

### 비교 쪽

| 논문 | 기준선에 Full KD 있음 | 같은 시간·연산으로 맞춘 비교 있음 | 무작위 대조 있음 |
|---|---|---|---|
| | | | |

- **같은 시간·연산으로 맞춘 비교**: 예를 들어 "같은 GPU 시간 동안 일반 KD를 돌린 것"과 비교했는가.
- **무작위 대조**: 고르는 방법이라면 무작위로 고른 것과 비교했는가.

## (2) 집계 (취합 담당)

체크표의 열을 세로로 센다. 분모를 반드시 적는다.

| 항목 | 수치 보고 | 언급 | 미보고 | 해당 없음 | 분모 |
|---|---|---|---|---|---|
| teacher 연산을 셈 | | | | | |
| teacher 준비 비용을 셈 | | | | | |
| 저장 용량을 보고 | | | | | |
| 실제 시간을 보고 | | | | | |
| 평균 정확도 외 지표를 보고 (지표별로 한 줄씩) | | | | | |
| 전체 학습 연산으로 환산 가능 | | | | | |
| 같은 시간·연산으로 맞춘 비교 | | | | | |
| seed 3개 이상 + 표준편차 | | | | | |

- 분모에서 "해당 없음"을 뺄지 넣을지를 항목마다 적는다. 분모가 달라지면 숫자가 달라진다.

## (3) 본문 초안 (취합 담당)

발견을 세 개로 쓴다. 문장마다 "N편 중 M편"이 들어가야 한다.

1. 어떤 비용이 가장 자주 빠지는가.
2. 측정 단위가 얼마나 섞여 있는가. (단위별 편수)
3. 평균 정확도 외 지표를 본 논문은 몇 편이고 무엇을 봤는가.

마지막 문장은 6절로 넘어가는 한 줄이다: 문헌이 비워 둔 칸을 같은 조건에서 직접 잰다.

## 판정이 애매할 때

- 본문에 "거의 들지 않는다", "무시할 만하다"만 있으면 **언급**이다.
- 부록에만 숫자가 있어도 **수치**다. 위치에 부록이라고 적는다.
- 다른 논문의 표를 인용한 숫자는 그 논문의 측정이 아니므로 **언급**으로 적고 출처를 단다.
- "미보고"로 적기 전에 [CHECKLIST.md](CHECKLIST.md) C항의 단어로 본문과 부록을 검색한다.
