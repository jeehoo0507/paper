## 방향

> 모든 방법을 **아낀 것 / 치른 것** 두 칸에 올린다. 문헌에서는 이 표가 대부분 비어 있고, 우리는 같은 조건에서 직접 채운다.

- 4절은 방법이 **무엇을 아끼는지**(비용식의 어느 항)를 정리한다.
- 5절은 논문들이 아낀 것과 치른 것을 **어디까지 적었는지** 센다.
- 7절은 같은 조건의 실험으로 빈칸을 채운다.

논문을 하나씩 소개하는 글이 되지 않도록, 각자 만드는 표는 전부 이 두 칸의 일부다.
**먼저 읽을 것: [CHECKLIST.md](CHECKLIST.md)** (열 이름, 분모, 원문 대조 규칙)

## 공통 규칙

1. **수치에는 위치를 적는다.** 표 번호나 쪽 번호가 없는 수치는 넣지 않는다.
2. **절감률에는 분모를 적는다.** 무엇 대비인지 (teacher 연산 / 전체 학습 / student 단독).
3. **논문에 없는 값은 "미보고"라고 적는다.** 빈칸이나 추측으로 채우지 않는다.
4. **단정하지 않는다.** "~한 논문이 없다" 대신 "N편 중 M편"으로 쓴다.
5. **논문별 설명 문단을 쓰지 않는다.** 방법은 표에 넣고, 본문은 축 전체에 대한 설명만 쓴다.

## 쓰지 않는 문장

- "기존 서베이는 비용을 다루지 않았다" → 서베이마다 확인한 결과를 표로 보인다.
- "효율 KD에서 그룹별 성능을 본 논문이 없다" → 몇 편 중 몇 편인지 센다.
- "MaskedKD가 전체 학습 비용을 27% 줄인다" → 논문의 절감률은 teacher 연산 기준이다.
- "벤치마크" → 통제 실험이라고 쓴다.
