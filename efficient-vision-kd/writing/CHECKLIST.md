# 꼼꼼히 챙길 것

이 논문이 논문 나열로 끝나지 않으려면 아래가 지켜져야 한다. 항목마다 담당과 끝났는지를 적는다.

## 방향 한 줄

> 모든 방법을 **아낀 것 / 치른 것** 두 칸에 올린다. 문헌에서는 이 표가 대부분 비어 있고, 우리는 같은 조건에서 직접 채운다. 채워 보면 축마다 치르는 칸이 다르다.

그래서 꼼꼼함이 필요한 곳은 세 군데다. 표의 열이 절마다 같아야 하고, "몇 편 중 몇 편"의 분모가 흔들리지 않아야 하고, 수치가 원문과 맞아야 한다.

---

## A. 표의 열을 하나로 고정한다

3절의 비용 항, 5절 체크표의 열, 6절에서 기록하는 항목, 7절 결과표의 열이 **같은 이름, 같은 순서**여야 한다.

| 묶음 | 열 | 뜻 |
|---|---|---|
| 아낀 것 | teacher 연산 | teacher 순전파만 센 값 |
| | 전체 학습 연산 | teacher + student + 선택 연산 |
| | 실제 시간 | GPU에서 걸린 시간 |
| | 준비 비용 포함 | teacher 학습, 캐시 생성, 선택 점수 계산을 더한 값 |
| | 저장 용량 | 저장한 teacher 출력의 크기 (시간·연산과 더하지 않는다) |
| 치른 것 | 평균 정확도 | |
| | 그룹별, 최저 그룹 | |
| | 클래스별, 꼬리·하위 클래스 | |
| | 보정 (ECE, NLL) | |
| | teacher 일치율 | |
| | 분포 이동, 손상 | |
| | 전이, 다른 과제 | |

- [ ] 3절 기호표 확정 (지후). 확정 전에는 4절 표의 열 이름을 임시로 둔다.
- [ ] 위 열 이름을 5절 체크표와 실험 결과표에 그대로 쓴다. 바꾸려면 전원에게 알린다.
- [ ] 용어 통일: Full KD, Short KD(Full KD를 짧게 돌린 것), teacher 예산(Full KD 대비 teacher 연산 비율).

## B. 분모를 고정한다

"N편 중 M편"을 쓰려면 N이 먼저 정해져야 한다. 지난 검수에서 18편, 14편의 분모가 문장과 맞지 않았다.

- [ ] **논문 목록 파일 하나**를 만든다 (`writing/papers.md`): 번호, 제목, 링크와 버전, 축, 하위 갈래, 포함 여부, 뺀 이유.
- [ ] 폴더의 PDF는 62편(Shrink 8, Skip 10, Reuse 14, Substitute 12, 측정 7, 평가 11)이다. Shrink 메모에만 있는 2편(PESF-KD, DIST)을 넣을지 정한다.
- [ ] teacher 연산을 줄이지 않는 Shrink 논문 5편(DKD, ITRD, Projector, PESF-KD, DIST)을 축 안에 둘지, 따로 뺄지 정한다. 이 결정에 따라 Shrink의 분모가 바뀐다.
- [ ] 집계 항목마다 "해당 없음"을 분모에서 뺐는지 적는다.
- [ ] 새로 추가할 논문: ShiftKD, Knowledge Distillation Must Account for What It Loses, End-to-End Energy Accounting. 2절과 평가 쪽 목록에 넣는다.

## C. 수치를 원문과 맞춘다

지난 검수에서 실제로 나온 오류 유형이다. 체크표를 채울 때 유형별로 한 번씩 확인한다. 전체 내역: [`../notes/audit/`](../notes/audit/README.md)

| 유형 | 실제 사례 |
|---|---|
| 분모 혼동 | MaskedKD의 −51%는 teacher 연산 기준인데 전체 학습 기준처럼 적음 |
| 우리가 환산한 값을 논문 수치처럼 적음 | "전체 학습 약 −27%"는 논문에 없는 값 |
| 조건 누락 | SRe2L 60.8%는 ResNet-101 student. ResNet-18은 46.8% |
| 단일 모델과 앙상블 혼동 | BYOT 81.04%는 앙상블, 가장 깊은 출구는 80.56% |
| 판본 차이 | FKD의 79.8 / 80.1 / 80.9%는 조건과 판본이 각각 다름 |
| 다른 표의 수치를 이어 붙임 | Teacher's Pet의 −1.46%p |
| 도달 시간과 최종 성능 혼동 | Weak-to-Strong의 4.75배는 특정 정확도에 처음 닿는 epoch 비율 |
| 조건이 다른 수치를 나란히 놓음 | DeDiER, DeTT의 Waterbirds 수치는 Group DRO teacher 기준 |

- [ ] 읽기 메모 PR #2의 수정 20건을 반영한 뒤 병합한다. 체크표는 병합된 메모를 보고 채운다.
- [ ] 수치마다 표 번호나 쪽 번호, 그리고 **본 판본**(arXiv 몇 판, 학회판)을 적는다.
- [ ] "미보고"로 적기 전에 본문과 부록에서 아래 단어를 검색한다: storage, disk, GB, memory, hour, GPU, wall-clock, throughput, latency, overhead, cache, pre-comput.
- [ ] 그림에서 읽은 값은 "그림 N, 눈대중"이라고 적는다.
- [ ] 교차 검수: 자기 축이 아닌 축에서 "수치" 칸 10개를 원문과 대조한다.

## D. 4절: 논문 목록이 아니라 축의 성질을 쓴다

- [ ] 축 문단은 세 가지만 쓴다: teacher 신호에서 무엇을 빼는가 / 무엇이 새로 드는가 / 이 축의 논문들이 공통으로 적지 않는 것.
- [ ] 축마다 **문헌 속 근거**를 모은다: 평균 정확도 외의 지표를 보고한 논문이 있으면 무엇이 어떻게 변했는지, 논문이 스스로 밝힌 한계나 실패 조건은 무엇인지.
- [ ] 관찰과 예측을 구분한다. Shrink와 Skip(샘플)은 우리 실험의 중간 결과가 이미 있으므로 "관찰"로 쓴다. Skip(구간), Reuse, Substitute는 실험 전이므로 "예측"으로 쓰고, 실험을 돌리기 전에 날짜와 함께 커밋한다.

| 축 | teacher 신호에서 빠지는 것 | 먼저 무너질 것으로 보는 지표 | 상태 |
|---|---|---|---|
| Shrink | 이미지의 일부 영역 | 최저 그룹, 손상 강건성 | 관찰 중 |
| Skip (샘플, 데이터) | 일부 이미지의 신호 전체 | 꼬리 클래스, 하위 클래스 | 관찰 중 |
| Skip (구간) | 학습 후반의 신호 | 보정, teacher 일치율 | 예측 (실험 전) |
| Reuse | 증강의 다양성 | 손상 강건성 | 예측 (실험 전) |
| Substitute | teacher의 상한 | 평균 정확도 | 예측 (실험 전) |

## E. 5절: 세기만 하지 않고 같은 기준으로 다시 읽는다

비용식을 만든 이유가 "논문마다 다르게 적은 비용을 같은 기준으로 읽는 것"이다. 가능한 논문은 보고된 절감률을 다른 범위로 환산해 본다.

- [ ] 환산에 필요한 값이 논문에 있는지 확인한다: teacher와 student의 연산량, teacher를 부르는 비율, 학습 길이.
- [ ] 환산식과 넣은 값을 표에 같이 적는다. 환산한 값에는 항상 "우리 환산"이라고 표시한다.
- [ ] 값이 모자라 환산할 수 없는 논문은 "환산 불가"로 적고 센다. 이 숫자도 발견이다.

## F. 실험 (지후)

현재(11/19 낮): 153칸 중 108칸 완료, 9칸 실패.

- [ ] CelebA 9칸이 GPU 메모리 부족으로 두 번 실패했다. 큐가 끝난 뒤 단독으로 다시 돌린다.
- [ ] CUB-LT는 teacher가 예전과 다르다. 새 결과에서 KD가 CE를 이기는지 먼저 확인하고 환경 선정 표를 고친다.
- [ ] 지금 수치는 전부 val이다. test는 실행 목록이 확정된 뒤 한 번만 평가한다.
- [ ] 실제 시간은 지금 기록으로 쓸 수 없다(4개가 GPU를 나눠 씀). 방법과 예산마다 단독으로, 실제 데이터 로딩을 포함해 다시 잰다. 도입부의 −23%도 이 값으로 바꾼다.
- [ ] 지표 평가 스크립트: ECE, NLL, teacher 일치율, 하위 10% 클래스, 손상 정확도. 저장된 가중치로 평가만 한다.
- [ ] 메인 데이터셋: Aircraft(같은 코드로 바로 가능), CIFAR-100(발표 수치 재현, 새 코드).
- [ ] 새 코드: 학습 길이를 바꾼 실행(Short KD 포함), Skip(구간), Reuse, Substitute.
- [ ] 토큰 6%에서 선택 규칙의 우열이 뒤집힌 결과는 seed를 채운 뒤에 쓴다.
- [ ] 탈락한 환경(CUB-200, CIFAR-10, 짧은 Imagewoof)도 환경 선정 표에 남긴다.

## G. 글 전체

- [ ] 본문의 모든 숫자에 출처를 단다: 문헌 수치는 표와 쪽, 우리 수치는 실행 목록.
- [ ] 주장과 근거의 대응표를 유지한다. 근거 없는 주장은 본문에서 뺀다.
- [ ] 한계를 명시한다: ImageNet-1k 없음, 방법은 재구현, 환경을 KD 이득으로 골랐으므로 결론은 KD가 도움이 되는 조건에 한정.
